To list users and change their roles, the app needs access to the Auth0 Management API:

  1. In Auth0, go to Applications → Applications → Create Application and create a Machine to Machine application.
  2. Authorize it for the Auth0 Management API with the permissions read:users, read:roles, read:role_members, create:role_members, delete:role_members, create:users and create:user_tickets.
  3. Set AUTH0_MGMT_CLIENT_ID and AUTH0_MGMT_CLIENT_SECRET to its Client ID and Client Secret (in Railway: Variables) and restart the app.

The README has step-by-step instructions.
