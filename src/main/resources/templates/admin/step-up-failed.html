MFA check didn't happen

You were sent to Auth0 to confirm with multi-factor authentication, but Auth0 sent you back without the step-up confirmation, so the role wasn't added.

An Auth0 admin should check:

  1. At least one factor is enabled under Security → Multi-factor Auth.
  2. The Require MFA for step-up Action has the latest code from auth0/require-mfa-for-step-up.js, is deployed, and is in the Actions → Triggers → post-login flow.
  3. The claim name in the Action matches the app's AUTH0_STEP_UP_CLAIM (default https://authexample.demo/step_up_mfa).

You can see what Auth0 sent on your profile page under ID token claims.
