Auth0 returned an error

The Auth0 Management API answered with HTTP 403:

{"message":"Insufficient scope"}

A 401 usually means AUTH0_MGMT_CLIENT_ID / AUTH0_MGMT_CLIENT_SECRET are wrong. A 403 usually means the Machine to Machine app is missing one of the permissions read:users, read:roles, read:role_members, create:role_members, delete:role_members (Auth0 → Applications → APIs → Auth0 Management API → Machine To Machine Applications).

Try again
