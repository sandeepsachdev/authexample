How it works

  1. You click Log in → Spring Security redirects to Auth0's Universal Login.
  2. Auth0 authenticates you and redirects back to /login/oauth2/code/auth0 with an authorization code.
  3. Spring Security exchanges the code for tokens, validates the ID token and creates a session.
  4. Log out clears the session and calls Auth0's /v2/logout.
